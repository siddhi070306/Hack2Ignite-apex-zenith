# Apex Zenith

AI-powered medical assistant for preliminary diagnosis and healthcare guidance, built for ASHA/ANM health workers in low-connectivity settings.

Work in progress — being rebuilt incrementally. Structure:

- `frontend/` — React + Vite + Tailwind client
- `backend/` — Express REST API (auth, patients, triage, voice, LLM analysis)
- `blockchain/` — Solidity anchor contract + deploy script

More detail will land here as each piece is built.
